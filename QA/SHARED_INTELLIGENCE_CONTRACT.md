# Shared Intelligence Substrate — initial contract

A shared capability is a **discipline or transformation**, not a new conversational persona.

## Allowed input

- visitor query or current movement representation;
- supplied conversation state owned by the active mode;
- evidence supplied by USE or the active specialist;
- canonical-resource candidates supplied by the system.

## Allowed output

- normalized observations/claims;
- synthesis material;
- epistemic classifications;
- language-ready draft material;
- doorway candidates;
- explicit state transitions: READY, DELEGATE, NEEDS_RETRY, UNAVAILABLE.

## Authority rules

The substrate never:
- decides which specialist to invoke;
- replaces a specialist response with its own voice;
- declares a canonical resource authoritative;
- fabricates missing evidence;
- silently converts failure into generic prose.

## Design test

The visitor should perceive one coherent system. Internally, the active mode may be highly specialized.
