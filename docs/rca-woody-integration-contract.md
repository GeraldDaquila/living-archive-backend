# RCA v1.1 Integration Contract

The canonical interpretation source remains `rca_profile_synthesis_library_v1.json`. The Woody snippet is a presentation layer.

## Required deterministic seam

1. Calculate four dimension means.
2. Apply public bands to each dimension.
3. Select the dominant relational pattern using the canonical precedence order:
   P_K, R_P, C_P, P_R, R_C, K_C.
4. Use an inclusive 0.80 threshold with decimal normalization or epsilon 0.000001.
5. If no relationship qualifies, select HighBalanced, Balanced, LowBalanced, or Uneven.
6. Select the independently authored Individual or Collective narrative.
7. Add strongest and lowest capacity context.
8. Render profile first, overall average second.
9. Use the same synthesized content for screen and print output.

## Audit finding

The current Woody snippet predates this contract. Its relational patterns are selected by descending score gap, not canonical precedence; its exact threshold uses a direct floating-point comparison; and some Collective text is created by pronoun replacement. These must be replaced during the controlled integration revision.

No LLM or external API is required for interpretation.
