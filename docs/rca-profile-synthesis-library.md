# Resonance & Coherence Assessment — Profile Synthesis Library

## Purpose
This library is the canonical interpretation layer for the Resonance & Coherence Assessment. It does not redefine the questionnaire, scoring bands, or constitutional circuit. It translates deterministic score patterns into developmental, plain-language orientation.

## Architecture
1. The assessment calculates four dimension scores.
2. The deterministic selector identifies a meaningful relational pattern, when precedence rules are met.
3. If no dominant relationship applies, profile shape is used.
4. The synthesis then identifies what is already available and opens an appreciative developmental doorway.
5. The overall indicator remains secondary.

## Individual and Collective lenses
The same numerical profile may have different implications for a person and for a group. Perspective-specific narratives are therefore authored explicitly; collective interpretation is not a pronoun substitution.

## Versioning
Changes to interpretive meaning should be reviewed here before implementation changes are made in the Woody snippet. The snippet is an implementation layer and must not become the canonical source of interpretation.

## v1 scope
This foundation contains the principal relational patterns currently supported by the assessment and the composition contract. It is intentionally structured for expansion after simulation and QA establish which additional patterns produce materially different orientation.
